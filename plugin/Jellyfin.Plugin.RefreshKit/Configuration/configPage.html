Jellyfin Refresh Kit

Handles the common stale app-shell and open-tab path across loaded plugins. Current generation: …

Serves a correctly revalidating index.html and injects the small client runtime that detects updates. Turn off to pass the shell through unchanged: the two settings below then have nothing to act on (no stamping, no automatic reloads), while this page and the public generation endpoints keep working.
Appends ?rkv=<generation> to eligible unversioned script/stylesheet tags that are visible when this transform runs. Their URL changes when the active generation changes; later outer-owned and runtime-created tags remain their owner's responsibility.
Defers while light-DOM probes observe playback, a rendered dialog, active editing, or fullscreen. Closed shadow roots and external players are outside those probes. Off = the client only logs that an update is available.
A plugin's saved settings can change what the web UI renders (a new tab, a new button), so saving them counts as an update. Bursts are coalesced and each plugin is rate-limited by the cooldown below. This applies to Refresh Kit too: saving this page reloads open tabs once (after the 10-second settle), which is how new poll/idle/budget values reach them. Turn off to exclude configuration content; loaded host/plugin code identities and active client assets are still tracked.
After the provider observes new content, it must remain stable for 10 seconds; a later scan publishes the leading change and opens a window this many minutes long. Further saves inside that window are coalesced and published when it expires — nothing is lost. 0 disables the cooldown (the 10-second settle still applies). 0 to 1440 (a day); a value outside that range is refused by the field or clamped to it. Blank restores 5.
One per line. Plugin name, install folder, GUID or assembly name. Use this if a plugin stores per-user preferences or runtime state in its plugin configuration and keeps bumping the generation on its own. An assembly name matches every assembly a plugin loads, bundled dependencies included (Newtonsoft.Json would exclude each plugin that ships it), so prefer the plugin's own name, folder or GUID.
How often a visible tab asks the server for the current generation. 15 to 3600 seconds (out-of-range values are refused or clamped); hidden tabs do not poll and catch up when shown. Blank restores 60.
Minimum time since the user's last click, key or scroll before an automatic reload. 0 to 300 seconds; 0 removes the wait apart from a fixed 1-second settle. Blank restores 5.
Ceiling on automatic reloads per rolling minute, shared by every Jellyfin tab of the same origin in one browser. 1 to 100; a reload the budget refuses waits, it is not lost. Blank restores 3.
Serves the client runtime with no-store instead of immutable. For debugging this plugin.
